# Tidewell Coffee (demo)

Demo of stages 1-3 of the static site workflow, using a fictional brand.

**To review:** open [`review/README.md`](review/README.md) on GitHub for full-page desktop and mobile screenshots of every draft (GitHub shows HTML files as source, so the screenshots are the easy way to view them).

- `/branding/` Branding page: color story, gradients, H1-H5 + paragraph, buttons, logo use
- `/draft-a/` Home, editorial split hero
- `/draft-b/` Home, bold full-bleed hero

Run locally: `npm run dev` then http://localhost:8000. Regenerate screenshots: `npm run build && npm run shots`.
